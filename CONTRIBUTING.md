# Contributing

1. Fork the repository and create a feature branch.
2. Keep changes focused with clear commit messages.
3. Open a pull request describing what changed and why.
4. Do not commit secrets, API keys, admin passwords, or live contact lists.

## Development notes

- Extension root is the folder that contains `manifest.json`.
- Dialer DOM selectors live only in `content/selectors.js` — run `IPECSSel.probe()` on the iPECS tab when repairing dial/hangup.
- Accounts API lives under `server/` (Vercel + Neon).
